# Changelog

## 0.31.2

- Added English and Simplified Chinese interface languages, with English as the default.
- Added an immediate language selector in Settings without restarting playback.
- Persisted language choices across reloads and portable backups.
- Localized page controls, dialogs, guidance, feedback, dates, and download alerts.
- Kept music titles, lyrics, comments, and platform protocol values unchanged.

## 0.31.1

- Extracted a standalone Web repository with independent build inputs.
- Added English development, deployment, security, and architecture documents.
- Added a GitHub Pages build and a verified CI deployment workflow.
- Added a static-hosting mode with local playback and clear companion limits.
- Isolated static application storage and caches by deployment path.

## 0.31.0 baseline

- Added local color-emoji fallback for Bilibili content.
- Added explicit application-update prompts and download-aware activation.
- Improved video speed control, clock synchronization, and bounded recovery.
- Improved live-stream reconnection and background-download persistence.
